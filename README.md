# MSA-comparison-pipeline
A Nextflow pipeline to compare alignments made by different aligners.

Typical workflow:

1. Run several MSA tools on the given input .fasta file(s)
2. Compare their output using rusty-metal
3. Then creates displays of their relative distances using
   - Multi-Dimensional Scaling (MDS)
   - Hierarchical clustering
4. Produce outputs

### Outputs:
| Name          | File type | Notes |
| ------------- | -------------- | ------------------------- |
| The MSA generated by each run of each tool | .fasta |
| The Rusty-Metal output | .csv |
| MDS output | .png | Check the stress value to see how accurate this visualisation is |
| Hierarchical clustering output | .png | Identical MSAs show as the branch edge hitting 0 in the middle of that group of MSAs |
| Summary details| .txt | MDS stress, and average dPos values |
